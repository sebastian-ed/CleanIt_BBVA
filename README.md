# Clean It BBVA V6
Actualización sobre V5; conserva datos, usuarios y config.js. No ejecutar schema.sql de V2.

1. En Supabase del proyecto BBVA, SQL Editor → New query: pegar y ejecutar `supabase/migration_v6.sql` completo. Es una migración, no elimina filas. Verificar que no haya otras políticas de lectura pública creadas manualmente.
2. Authentication → configuración de Sign In / Providers → habilitar Anonymous Sign-Ins. No confundir con habilitar registro público por correo. La carga crea una sesión técnica anónima sin pedir usuario o contraseña. Si está habilitado CAPTCHA obligatorio, configurar su integración antes de usar; esta versión no incluye widget CAPTCHA. Para URL pública, se recomienda proteger con CAPTCHA y límites de abuso antes de abrirla masivamente. El bucket sigue privado, tamaño máximo 10 MB, JPEG. Los visitantes pueden cargar, pero no consultar fotos ni días ni modelos Gemini. Un supervisor inicia sesión con su usuario habitual. El historial público es solo recibos locales, no datos de otros operarios.
3. Reemplazar index.html, style.css, app.js, ocr.js y supabase/functions/analyze-bbva/index.ts. Conservar config.js. Desplegar función: `npx supabase@latest functions deploy analyze-bbva --no-verify-jwt --project-ref uzzbvirtxgqxwyxtmxal`. La función valida el JWT y rol internamente. Solo permite OCR de la última foto propia para usuarios sin rol supervisor.
4. Publicar frontend GitHub Pages y Ctrl+F5. Probar en incógnito: carga sin login, supervisor exige contraseña, las fotos son privadas. Probar guardar borrador, agregar y quitar filas, editar importe, confirmar revisión y actualizar mes.

## Cálculo
El resumen mensual refleja el borrador visible inmediatamente (etiquetado sin guardar). Guardar borrador persiste incluso con filas dudosas; confirmar exige revisar todas. Exportar exige guardar primero. Las lecturas de cierres anteriores no se incluyen cuando hay una foto nueva pendiente. El importe por fila se actualiza al editar. Particular SI suma valor leído o tarifa diaria; abonado o NO suma cero. El cupo incluye todos los SI. No se suma el extra a la facturación particular automáticamente. OCR y Gemini siguen siendo alternativas; no se garantiza exactitud sin revisión. La sesión técnica anónima permite OCR automático en el navegador, que debe permanecer abierto hasta terminar. Si falla, supervisor puede reprocesar la foto guardada. No se implementó backup Drive/Sheets.
